# Atlas SAP

Trilha pessoal de estudo do ERP SAP com visão de arquiteto: como cada módulo funciona, que documentos e controles usa, onde integra com os outros e onde o padrão tem limites. Conteúdo em português, inglês e espanhol, baseado em fontes oficiais da SAP.

**Versão atual:** 1.0.1 · [Changelog](CHANGELOG.md) · [Regras de versionamento](docs/VERSIONAMENTO.md) · [Arquitetura](docs/ARQUITETURA.md)

**Site:** https://gulaaleff.github.io/atlas-sap/

## O que tem

| Seção | O que faz |
| --- | --- |
| Painel | Sessão do dia (revisão, capítulo do módulo atual, desafio), sequência de dias, nível, XP e progresso por módulo |
| Trilhas | As 6 trilhas e as páginas previstas |
| Mapa de integração | Visão global: clique numa solução para ver com quem ela troca dados |
| Módulos | Seletor com SD, MM, FI e CO abertos; PP, QM, PM, PS e outras soluções SAP bloqueadas |
| Página do módulo | **Estudo** (8 capítulos com pergunta-guia e atividades), **Revisão** (quiz em 6 temas) e **Integrações** (só do módulo) |
| Revisão | Cartões com repetição espaçada de todos os módulos |
| Desafio | Um caso de cliente por módulo, com quatro desenhos avaliados |
| Glossário | 102 termos SAP em PT, EN e ES, com busca e filtro por módulo |
| Novidades | Histórico de versões; a versão nova aparece em destaque na primeira visita |
| Como usar | Rotina diária e semanal e a base de cada técnica de estudo |

O progresso fica salvo no navegador. Em outro dispositivo, começa do zero.

## Publicação

O site é publicado pelo GitHub Pages a partir da branch `main`, pasta raiz. Não há build: qualquer mudança enviada para `main` vai ao ar em alguns minutos.

Repositório público (GitHub Free): o código fica visível, e o `index.html` tem `noindex` para buscadores não listarem o site.
